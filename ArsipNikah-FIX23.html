Tentang MyArsip Nikah

Website ini merupakan rancangan awal sistem pengarsipan data pernikahan untuk Desa Pelang Kidul.

Versi demo menyimpan data di browser perangkat menggunakan localStorage. Untuk penggunaan pemerintahan/desa secara nyata, perlu ditambahkan database server, login berbasis peran, audit log, enkripsi, backup, serta kebijakan akses dokumen.

Aturan Struktur Data

Satu pernikahan menggunakan satu data utama. N Masuk menjadi pintu utama untuk pernikahan yang ditangani Desa Pelang Kidul. Data wali pada N Masuk hanya jenis wali, nama wali, dan hubungan wali. Surat Wali digunakan terpisah untuk kebutuhan pernikahan di luar desa. N Keluar hanya dibuat jika benar-benar diperlukan secara administratif dan tidak dibuat otomatis untuk pasangan satu desa.
